# Prior art

## The claim

Rudder's claim is the combination, in one vault system, of:

- a per-vault mandate stored in a registry (`contracts/src/StrategyRegistry.sol:115-140`);
- several bounds at once: range width, centre shift, minimum rebalance interval, TWAP distance and price impact (`contracts/src/libraries/EnvelopeLib.sol:50-69`, `contracts/src/RudderVault.sol:371-386`, `contracts/src/RudderHook.sol:290-293`);
- instant tightening with a delayed loosening path (`contracts/src/StrategyRegistry.sol:114-140`);
- exits that do not consult oracle state, a registry or an unbounded loop (`contracts/src/RudderVault.sol:312-328`, `contracts/src/RudderVault.sol:716-731`, `contracts/test/WithdrawIndependence.t.sol`);
- performance fees charged per depositor against that depositor's hold basket (`contracts/src/RudderVault.sol:312-323`, `contracts/src/libraries/NAVMath.sol:32-43`); and
- a flow-invariant alpha ranking that scores vault return against the hold benchmark (`contracts/src/StrategyRegistry.sol:157-189`, `evidence/flow_invariance.json`).

Rudder reuses known pieces: TWAP oracles, performance fees against a benchmark, vault shares and hook-level range checks. The combination and the code-level coupling are the subject of this document.

## Limits

- The two datasets and the three ETHGlobal/ERC-8004 source pages are a searched set, not the whole ecosystem. Zero hits inside them is not proof of absence outside them.
- Keyword search under-reports paraphrases, synonyms, private repositories and behaviour found in source code.
- Explorer source pages for TickRangeHook and M0 Tick Range Hook expose source lines but no repository commit hash; the rows state that directly rather than inventing a commit.
- ArrakisPrivateHook has a source flag set in hooklist, but the explorer source fetch was blocked. The row stays at description level.
- Repository reads are scoped to the files named above. A missing fee or track-record mechanism means none was found in those files, not none anywhere in a project.
- Directory `Cohort` values are builder cohorts, not necessarily hookathon numbers.
- The Rudder claim elements are backed by the code and tests named in "The claim"; no external project row is treated as a legal or priority judgment.

## What we do not claim

- We do not claim global priority for the combination. We report what appears in the searched set and in code read for the named repositories.
- We do not claim that none of the 5271 hooklist entries, or none of the entries outside these datasets, has a similar design.
- We do not claim a security audit, deployment readiness or partner integration from this comparison.
- We do not claim that description-level rows have no implementation; their source was not read.
- We do not claim that the two manual findings both reproduce. The count findings reproduce in the searched directory; the LP-management characterization does not.
